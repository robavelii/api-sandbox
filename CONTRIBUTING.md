# Contributing

Start from the latest main and create a topic branch following AGENTS.md. Use one coherent feature or fix per pull request. Stacked branches are allowed; clearly name the prerequisite PR and target its branch until it merges.

Before opening a PR, run the checks documented in README.md. Describe the user-visible behavior, tests performed, and any migration or deployment requirements. CI validates branch names and prohibits co-author trailers. Major feature commits retain the repository owner's configured Git identity; maintenance commits use the Codex identity described in AGENTS.md.

Main requires a pull request and successful policy checks. Review and merge remain the repository owner's responsibility.
